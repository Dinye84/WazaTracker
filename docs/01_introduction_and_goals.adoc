== Introduction and Goals

** What is the main purpose of this project?

To learn how to plan, design, develop, and publish web applications.

** What does this app do?

WazaTracker (working name) helps coaches improve groups of individuals and sports teams.

More precisely, it helps sports coaches to:
Track activities performed during training sessions.
Get statistics on which activities the team has trained during a season.
Get valuable insights into what the sports team's focus has been during a selected season.
See if other drills need to be implemented based on previous seasons.
Add comments during a session, for example if the team needs to train more on specific drills.

The purpose/goal of the app is to make it easier to track the progress of a sports team by providing
an easy way to track which exercises were performed and what the focus of each individual training
session was. The purpose is to be able to see what focus the coach has had during a season and to
shift focus if needed for the next training session or perhaps for the next season. The user will be
able to check which exercises and techniques were performed during a session, and the app will
automatically calculate the percentage focus of all combined training sessions and split it into
categories.

=== Quality Goals

* Offline-first PWA. Internet access is not required for normal use, but is required when synchronizing data with the server.
* The app needs to be user-friendly for new users.
* The app should limit the amount of personal information required.
* The app should support at least 50 simultaneous users.
* The app needs to be scalable for more users and organizations.
* 95% of API calls should be answered within 500 ms with 50 simultaneous users.
* The error rate should be below 1%.
* API performance and error rates will be verified through automated load testing with k6.
